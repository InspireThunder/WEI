# WEI · AI 资讯热点

这个仓库用于每天自动生成一份可公开访问的 AI 最新资讯网页。

## 使用方式

- 公网入口：`https://inspirethunder.github.io/WEI/`
- 本地入口：`file:///Users/cdkfweitao/Documents/AI%E8%B5%84%E8%AE%AF%E7%83%AD%E7%82%B9/index.html`
- `index.html` 是一级入口，展示每日资讯列表。
- 在 `index.html` 中点击日期进入当天日报：`daily/YYYY-MM-DD.html`。
- `archive.html` 保留为同样的每日资讯列表入口。
- 历史日报保存在 `daily/`。
- 每日结构化数据保存在 `data/YYYY-MM-DD.json`。

## 自动化流程

Codex 自动化任务每天抓取最近 24 小时内的中英双语 AI 资讯，整理为中文摘要，只保留热度最高的 10 条，写入当天 JSON，然后运行：

```bash
node scripts/build-site.mjs
```

脚本会根据 `data/` 中的 JSON 文件重新生成每日列表入口、每日归档页和每日资讯列表页。`index.html` 始终是固定一级列表入口，不按日期改名；当天日报通过列表进入。

## 数据原则

- 优先官方博客、论文、开源仓库、监管机构、公司公告等一手来源。
- 增加中国资讯网站来源，包括机器之心、量子位、36氪、钛媒体、虎嗅、雷峰网、智东西、InfoQ 中文站、澎湃新闻科技、财新科技等，用于覆盖国内 AI 热点。
- 科技媒体可以作为补充来源，但转载内容会被去重，并尽量追溯到官方原始链接。
- 无法确认发布时间或来源可信度较低的内容会降低优先级。
- 信息不足时可以生成空日报，但不能编造资讯。
